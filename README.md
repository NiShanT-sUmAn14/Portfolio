# Portfolio

Hi, I'm Nishant Suman, a third-year B.Tech IT student building skills in full-stack development (Java, MERN) and AI/ML. This portfolio brings together my projects, tech stack and ways to reach me.

**Live Demo:** [https://nishant-suman14.github.io/Portfolio/](https://nishant-suman14.github.io/Portfolio/)

## Features

- Clean, responsive layout
- Smooth scrolling with Locomotive Scroll
- Scroll-based animations using GSAP
- Projects section with project cards
- Contact details and social links

## Tech Stack

- HTML5
- CSS3
- JavaScript
- [GSAP](https://gsap.com/)
- [Locomotive Scroll](https://locomotivemtl.github.io/locomotive-scroll/)

## Projects Showcased

- **E-commerce** –  Online shopping website with product listing, cart and checkout flow, built with the MERN stack.
- **RAG** – Retrieval-Augmented Generation app that answers questions from your own documents using embeddings and an LLM.
- **Redis** – Project using Redis for caching to speed up data access and reduce database load.

## Run Locally

```bash
git clone https://github.com/NiShanT-sUmAn14/Portfolio.git
cd Portfolio
```

Then open `index.html` in your browser (or use the VS Code Live Server extension).
